# Open Programs 首轮可比实验

在固定的 10 个合成维护任务上，Open Programs 通过 **73/90** 个阶段，2.4 适配基线通过 **70/90**。完整三阶段序列分别通过 **19/30** 和 **17/30**。这组任务的主对照差距较小；关闭失败反馈组通过 41/90，关闭复用组通过 68/90。

## 方法与数据

- 每个任务包含初始修复、需求变更、依赖变更三个阶段；每组重复 3 次，共 360 阶段。8 个开发任务、2 个 held-out 任务。任务、固定 oracle 和预算见 [manifest](../../benchmarks/open_programs/manifest.json)。
- 同一阿里云 `qwen3.8-max-0902`、相同输入快照、Patch 输出 schema、隔离镜像、验收检查和审批边界。每阶段最多 4 次模型请求、16000 个报告 token、90 秒。
- 2.4 组使用原 AgentRunner 加共同外部 OCI 验收和应用服务；它衡量这一适配方式。3.0 组使用 OpenCompiler，消融组分别去掉 capsule 选择或失败反馈。
- 四个并行 worker。验证工作在同一机器同时进行，时延为本轮观测的阶段墙钟时间。fixture-operator 提供测试授权，人工介入耗时没有计量。
- [逐阶段记录与统计](2026-10-23-open-programs-matrix-v2.json)包含所有失败。矩阵源码摘要：`77ecfdfa52c772ab8354ef0b3d016b466492a044e6b83d1865f513974a9af98f`；manifest 摘要：`082e54f13c893872c7cb7e122d38e81391a7fd71d2a17e69a5300a3fbff9385d`。

Open Programs 的请求数比适配基线少 27 次，总 token 为 277382，对照为 258527。模型价格基准尚未核对，费用字段保留 null。三次重复的阶段通过数分别为：2.4 的 22/25/23、Open Programs 的 26/23/24、关闭复用的 22/23/23、关闭反馈的 13/13/15，每次分母为 30。

开发集合通过数分别为 55/72、56/72、52/72、31/72；held-out 集合分别为 15/18、17/18、16/18、10/18。当前任务数量用于观察机制和发现失败，生产仓库泛化仍需更大的独立集合。

四组合计 252 个接纳结果，均满足本轮固定验收检查；已记录的 252 次应用前工作区比较中，未授权改写为 0。73 个 Open Programs 接纳结果中选中复用的次数由逐阶段数据记录；总选择 21 次，选择后仍需当前上下文验证。预算用尽、被拒绝和 blocked 均保留为失败阶段，没有从分母剔除。

证据消融采用只读反事实检查：在具有**前一阶段已接纳实现**的 46 个变化事件中，16 个旧实现无法通过当前 oracle。若直接沿用旧成功，这 16 个事件会被错误接纳。原始驱动还检查了 14 个前序未接纳候选，分析明确排除它们；驱动已将此前序条件作为过滤规则。生产验收路径始终保持证据检查启用。

本轮共 1058 次模型请求、1051532 input tokens、154630 output tokens。逐阶段使用量之和与共享 provider meter 完全一致。

## 方法修正与复现边界

[第一轮矩阵](2026-10-23-open-programs-matrix-v1.json)共 1103 次请求。其 2.4 适配提示缺少完整 Patch 输出 schema，68 次失败发生在类型检查，最终为 17/90。核查后补齐同等契约，完整重跑得到上表的 70/90；第一轮作为方法调试记录保留，不参与上表比较。

第二轮之后只修改了 CLI 的当前证据解释/导出消费者，以及驱动的反事实样本过滤。公开数据通过前序状态进行同样过滤。求解、执行、工作区和固定 oracle 路径与本轮相同。最终交付的普通文件 SHA-256 见 [源码记录](2026-10-23-open-programs-source.json)；矩阵各源码项采用 canonical JSON 文本摘要，算法见 [复现说明](../../benchmarks/open_programs/README.md)。
